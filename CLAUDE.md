@AGENTS.md

Skills, in `.claude/skills/`:

- `verify`: run what CI runs, fastest first, and read a failure.
- `fix-a-bug`: a failing test first, then the fix, the docs, the changelog line and the commit.
- `add-a-setting`: a spec field, annotation, operator flag or Helm value, end to end.
- `write-docs`: where pages live, the voice, versioned links, and the tests that hold the docs to the code.
- `e2e`: the end-to-end and Helm smoke tests on kind, one spec at a time, and reading a failure.
