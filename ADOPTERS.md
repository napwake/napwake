# Adopters

Teams that use Napwake to pause real workloads. If yours does, add it here. It shows other teams Napwake is in use, and tells us what to build next.

## Add yours

1. Edit this file, on GitHub or in a fork.
2. Add a row to the table, in alphabetical order:
   - **Company,** linked to its website.
   - **What Napwake pauses,** such as "preview environments" or "staging, 40 workloads".
   - **Clusters,** how many you run it in. Optional.
   - **Since,** the month you started, such as Nov 2026. Optional.
3. Sign off the commit, as every commit here is. GitHub's editor does it for you. On the command line, use `git commit -s`.
4. Open a pull request.

Rather not name your company? Tell us in [Show and tell](https://github.com/napwake/napwake/discussions/categories/show-and-tell) instead, and leave its name out.
