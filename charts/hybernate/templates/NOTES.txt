Hybernate is installed in namespace {{ .Release.Namespace }}.

The forecast, which learns when each workload is busy, counts hours and
weekdays in {{ .Values.timezone }}.
{{- if eq .Values.timezone "UTC" }} Set timezone to your users' zone, such as
--set timezone=Europe/London, so workloads wake for their mornings all year,
through daylight saving.
{{- end }}

1. Check the operator and the doorman are running:

   kubectl get pods -n {{ .Release.Namespace }}

2. See which workloads are idle and what they cost, with the kubectl plugin:

   kubectl hybernate scan

3. Opt a workload in, measuring it first so nothing is paused yet:

   kubectl annotate deployment my-app -n my-namespace hybernate.io/dry-run=true
   kubectl label deployment my-app -n my-namespace hybernate.io/managed=true

   Label a namespace instead to opt in everything in it.

   Applied by Argo CD or Flux? Before enable, have it leave replicas to
   Hybernate, or it scales the workload back up after every pause:
   {{ $docs }}guides/gitops/

   When you're ready, let Hybernate pause it while idle:

   kubectl hybernate enable my-app -n my-namespace

4. Check what it's doing:

   kubectl get managedworkloads -A
